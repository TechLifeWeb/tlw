Structured procrastination, formalised. A todo system built around readiness instead of priority or time, in one plain text file.How to create a working Forster list in a single text file

I've been tracking tasks in a Forster list for over a month now. This list lives in an A6 squared notebook that goes with me (almost) everywhere. It's been a wonderful experience, giving me a great balance between structure and freedom during what's been a rather difficult year. But life continues and there are things to be done.

This week's (rather lengthy) post shows you how to create a Forster list in a single text file, that works just as well as its analog counterpart. Comes with tips for both digital and paper todo lists, and an opinionated reminder that you don't have to choose just one and stick with it for life. This is advice worth considering whether you are a Forster list user or not.
