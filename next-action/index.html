Your tasks. A simpler front end.

Test Todoist sign-in, read your tasks, and create one clearly named test task. This page uses plain HTML, CSS, and JavaScript.

Not connected.

1. Connect your account

Sign in on Todoist and return here. Each visitor connects their own account.

The access token stays in this page’s memory. Reloading or closing the page disconnects it. No task data or tokens are saved to disk by this app.
Hosting setup — site owner, once

Upload this file as index.html on an HTTPS website. Enter its exact public address below and download the configuration. Upload that JSON file beside this HTML file, then open the public page and connect.

The JSON contains public addresses only. It contains no password, API key, or client secret. The JSON URL must be publicly accessible, even if you protect the app page.

2. Read and refresh

Read up to 20 active tasks. Change a task in Todoist, then refresh here to check incoming changes.

    Tasks will appear after connecting.

    3. Test writing

    Create one task in your Todoist Inbox. You can then edit and complete that test task here, checking the changes in Todoist.

    Existing tasks are read-only in this test.

    Optional local-file connection test

    If opening this file directly from your computer, use a personal API token to test task access only. This does not test the hosted sign-in flow. Enter the token here, never in chat.
